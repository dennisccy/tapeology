# Project story so far

Tapeology is a real-time tape-reading tool for US stocks: you point it at one ticker and it tells you, in plain language, what the order flow is doing right now — and how sure it is.

## How it has grown

An earlier run built the **practice mode** first, proving the hard ideas on a deterministic simulator before touching real market data. The single-ticker cockpit came to life — a live quote, a running trade list, the core flow readouts, a confidence score, plain-language observations, and an event log. The product's defining habit of honesty was established early: it recognizes when heavy buying or selling is being *absorbed* (the price refuses to move) rather than mistaking that pressure for control.

This session then brought in real US market data through that same engine without ever inventing a number. A data-source selector (Live, Historical, or Simulated) arrived first, followed by real historical replays, a two-stage aggressor classifier, a candlestick price chart with tape-state markers, pause and resume, and a local-time historical picker with one-click US-session presets. A third wave added vendor responsiveness: concurrent trades-and-quotes fetching, a window cache for near-instant re-watches, a pre-loaded symbol universe, and every vendor call bounded by a real network-level deadline with actionable error messages.

A fourth expansion addressed the experience of watching the product in action: immediate Watch feedback, explicit error messages for slow or unreachable backends, an honest "waiting" state when no data has arrived yet, and inline validation for bad input. The time-display layer was then overhauled — the chart axis shows real market clock times, and a custom day-month-year date field replaced the native picker everywhere. Iteration 12 completed the replay-speed control, parallel-chunk long-window loading, and relative tape-state gates.

Iteration 13 declared the goal achieved, but two real-data legs had been validated only against hand-built synthetic fixtures. The user verified they still failed on real Alpaca data, and both were immediately reopened as J-36 and J-37.

Iteration 14 closed those two defects with real evidence. The reference case is GME's sharp drop on 14 May 2024: a committed real SIP fixture carrying 17,342 actual trades now replays through the engine and resolves correctly to **seller_control** at confidence 0.925, where the same replay with the old logic stays stuck on "unclear" at 0.200. The fix was twofold — historical replay now pulls the SIP consolidated feed (which has realistic, tight spreads) instead of the noisy single-venue feed that produced misleadingly wide quotes, and the engine now treats a momentarily wide quote as a confidence dip rather than a hard veto on an otherwise clear move. Long historical windows were restructured so the cockpit begins filling from the very first piece of data while the rest streams in behind it, making the "shorter range" message a true last resort. The engine's number-crunching was rewritten to handle tens of thousands of real prints per second without stalling, with values byte-identical to the old approach. The test suite — now at 283 automated tests running without live credentials — is the definitive proof: these reads are correct, and the regression floor for every earlier capability is held firm. All 37 must-have capabilities are complete.

## What it can do today

The product lets users watch one US stock at a time — in simulated mode, a real past session replayed at any speed (including speed changes mid-replay), or a real live feed — and read the tape in plain language: buyer control, seller control, bid or ask absorption, or an unclear tape, each with a confidence score, live quote, running trades list, and plain-language observations. Users can search for a stock by name, choose a data source, and pick historical windows in their own local time using one-click US-session presets entered via a custom day-month-year date field. A candlestick price chart shows true clock times on its axis with colored tape-state markers and a bar-size selector. Users can pause and resume a running watch. Every Watch click gives immediate feedback; connection failures and slow requests surface explicit error messages. Re-watching the same historical window is near-instant from a local cache. Long historical windows including the full trading day load and begin playing immediately without a refusal. A stock making a clear directional move — even on real consolidated-tape data — reads correctly as buyer or seller control. Dates appear consistently in day-month-year format across the entire product.
