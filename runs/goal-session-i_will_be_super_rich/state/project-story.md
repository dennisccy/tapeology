# Project story so far

Tapeology is a real-time tape-reading tool for US stocks: you point it at one ticker and it tells you, in plain language, what the order flow is doing right now — and how sure it is.

## How it has grown

An earlier run built the **practice mode** first, proving the hard ideas on a deterministic simulator before touching real market data. The single-ticker cockpit came to life — a live quote, a running trade list, the core flow readouts, a confidence score, plain-language observations, and an event log. The product's defining habit of honesty was established early: it recognizes when heavy buying or selling is being *absorbed* (the price refuses to move) rather than mistaking that pressure for control.

This session then brought in real US market data through that same engine without ever inventing a number. A data-source selector (Live, Historical, or Simulated) arrived first, then real historical replays — enter a stock, pick a past date and window, and watch that session's real trades and quotes flow through the unchanged engine. A two-stage aggressor classifier resolved nearly all "unknown" trade sides. A candlestick price chart appeared above the cockpit with colored tape-state markers and a bar-size selector. Pause and Resume let a user freeze the cockpit at any moment. A local-time historical picker with one-click US-session presets fixed an earlier timezone gap.

With twenty journeys passing, a spec expansion raised the bar. The Watch button now always gives feedback within one second. Slow or unreachable backends surface an explicit error. Connection failures are shown rather than swallowed. Invalid input is caught inline. A connected stream with no data shows an honest "waiting" state; a background feed failure surfaces as a clear error, never a frozen screen.

The final iteration completed the **vendor responsiveness** requirement — the last three unbuilt capabilities. Historical loading is now fast by design: trades and quotes are fetched at the same time rather than one after the other, a needless extra round-trip was removed, and fetched windows are cached so re-watching is near-instant. Symbol search pre-loads the full stock list in the background at startup so the first keystroke is never a cold stall; rapid typing cancels older in-flight requests so results never arrive out of order. Every call to the data vendor is now bounded by a real network-level deadline, and an oversized historical window gives a specific, actionable message ("that window is very high-volume — try a shorter range") rather than a vague retry prompt. All 30 required capabilities now pass with concrete browser and backend evidence.

## What it can do today

The product lets users watch one US stock at a time — in practice (simulated) mode, a real past session replayed at any speed, or a real live feed — and read the tape in plain language: buyer control, seller control, bid or ask absorption, or an unclear tape, each with a confidence score, live quote, running trades list, and plain-language observations. Users can search for a stock by name (fast, even immediately after a restart), choose the data source, and pick historical windows in their own local time using one-click US-session presets. A candlestick price chart appears in simulated and historical modes with colored tape-state markers and a bar-size selector. Users can pause and resume a running watch. Every Watch click gives immediate feedback. A connected stream with no data shows an honest waiting state; a background failure surfaces as an explicit error. Re-watching the same historical window is near-instant from a local cache. An oversized window returns a clear, actionable error message. All 30 must-have capabilities are complete.
