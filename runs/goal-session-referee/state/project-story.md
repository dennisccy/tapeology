# Project story so far

Tapeology is a research app with three screens — a live-tape Cockpit, a Structure page that maps where a stock tends to bounce or stall, and a Desk that scans for chart setups and logs every signal it sees, honestly, without ever placing a real trade.

## How it has grown

This chapter, "The Referee," is teaching the product to check its own homework — telling a pattern noticed by eye apart from one imagined in noise. It began by confirming everything old still worked, then built the checking basics behind the scenes: a shared evidence record, a statistics engine for judging whether a pattern is real, and a way to compare every signal against fair "nothing happened" moments.

A permanent notebook came next, locking in each research question's start date the instant it is written so it can never be backdated; then came the actual judge, which measures a question against its fair comparisons and returns one permanent verdict no later check can change. Testing both turned up two soft spots — a failed self-check that could still let a false answer slip through, and a damaged record that could vanish without warning — both closed the same rounds they were found.

The Desk page then got something to actually click: a "Referee Registry" section listing candidate research questions with plain-English reasons and live evidence counts — pick one, confirm, and it registers for real. Checking the new screen caught a wrong "days until ready" number claiming some questions were ready right now when the honest wait is 50 to 119 days; it was fixed the same round.

Most recently, the product gained its first hard promotion rule: its core trading strategy can never be swapped for a new one unless a genuine certificate from the fact-checking system backs it up, with no way around it — proven by minting a real certificate and trying every way to sneak past it, with each attempt honestly refused. The Registry table also grew a sixth candidate question, the missing partner to one already there. One open item remains on record: the certificate names which strategy it is for, but nothing yet double-checks that the evidence behind it truly came from that strategy — nobody can reach that gap today, but it is flagged to close before it could matter.

## What it can do today

The product lets users watch the live tape on the Cockpit, look up a stock's price map on the Structure page, and scan chart setups on the Desk — the same three screens as before. On the Desk page, users can open "Referee Registry" to see six candidate research questions with live evidence counts and register one for real. Behind the scenes, the product's core trading strategy is now protected — it cannot be replaced unless a real check from the new fact-checking system backs the replacement.
