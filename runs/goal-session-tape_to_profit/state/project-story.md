# Project story so far

Tapeology watches a stock's live trade-by-trade order flow and tells you, moment to moment, whether buyers or sellers are in control — and this chapter is teaching it to measure whether that read actually makes money.

## How it has grown

This chapter, the profit-research era, opened with a check-up confirming the underlying product — cockpit, journal, replay studies — still worked before any profit-measuring pieces existed. It then gained a direct connection other tools and AI assistants can read from, a navigation menu that builds itself automatically, and a permanent, tamper-checked library for historical market data locked forever as "practice" or "final exam" data the moment it's saved.

Next came the payoff: an engine that runs a defined trading strategy against that stored data and honestly reports whether the simulated trades would have won or lost money, always shown beside a random-guessing comparison so nothing looks better than it is. The product then gained a permanent memory — a tamper-proof scoreboard holding one honest row per trading-strategy improvement, forever, with no way to edit or erase an entry. Its first entry, the founding baseline, went live: a small loss in practice, a small gain on the final exam, both honestly flagged as too few trades to mean much yet.

This latest round put that scoreboard on screen for the first time: a new Performance page, reached from a fourth link atop every page, shows the founding entry and a summary of the strategy version currently in use — numbers matching, value for value, what's stored behind the scenes, nothing rounded or recalculated. Every previously-working part of the product was re-checked and confirmed unchanged. Next: trying an alternative version of the trading strategy experimentally, without touching the one currently live.

## What it can do today

Users can type in a stock ticker (or a built-in demo ticker) and watch Tapeology read live trade-by-trade action, classify who's in control, write trading theses into a journal, and run replay studies against past data. The product also stores and replays historical market data, runs a defined strategy against it for an honest profit-or-loss report beside a random-guessing comparison, and now shows that scoreboard on its own Performance page next to the strategy currently in use — all readable by AI assistants through a direct connection.
