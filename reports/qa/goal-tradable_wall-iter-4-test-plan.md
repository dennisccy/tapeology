# Goal Iteration 4 — J-04 Edge Report Functional Test Plan

**Phase:** goal-tradable_wall-iter-4
**Date:** 2026-07-14
**Frontend Present:** no

## Phase Goal

Deliver the honest 3-way edge report (`v1` vs `structure_tape` vs `structure_tape_map`) — extend the era-3 measurement stack additively so all three strategies can be compared per **strategy × class × side × reaction** cell (n≥5 or `insufficient_sample`, train/hold-out never pooled, feeds never pooled, null baseline, full PnL register) — served from the new canonical `GET /research/edge-report` (+ read-only MCP proxy), all keyless over the committed fixture.
